# 🐈 Sandbox
Sandbox es un emprendimiento creativo donde la tecnología y el diseño se encuentran para dar vida a ideas originales. Este espacio nace con la intención de explorar nuevas formas de expresión a través de stickers, impresión 3D y diseños inspirados en la informática, la cultura digital y el universo maker.

Este proyecto también representa mis primeros pasos en el desarrollo web, utilizando HTML, IA y GitHub Pages para crear y publicar mi propia página en Internet.

🚀 Este es el comienzo de Sandbox: un espacio para experimentar, crear y transformar ideas en proyectos.

# Proyecto
Este es un proyecto en desarrollo y constante actualización para su mejor funcionamiento. Por lo tanto, puede haber errores
