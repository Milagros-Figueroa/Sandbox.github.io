## Sobre el proyecto

**Sandbox** es un emprendimiento creativo hecho en Buenos Aires 🧉 donde la tecnología y el diseño se encuentran para dar vida a ideas originales: stickers, calcos para termos, piezas impresas en 3D y diseños inspirados en la informática, la cultura digital y el universo maker.

Este repositorio también marca mis primeros pasos en el desarrollo web: aprendí armando mi propia tienda con **HTML, CSS, JavaScript, ayuda de IA y GitHub Pages**.

## ¿Qué podés hacer en el sitio?

- Explorar el **catálogo** de diseños
- Sumar productos al **carrito**
- Enviar tu pedido directamente por **WhatsApp**
- Pedir **combos y diseños a medida**
## Tecnologías

| Herramienta | Uso |
|---|---|
| HTML | Estructura de las páginas (inicio y detalle de producto) |
| CSS | Estilos del sitio (`estilos.css`) |
| JavaScript | Catálogo de productos y carrito de compras |
| GitHub Pages | Hosting gratuito |
| IA | Asistencia durante el desarrollo |

## Estructura del proyecto

```
Sandbox.github.io/
├── assets/          # Logo e imágenes
├── carrito.js       # Lógica del carrito de compras
├── estilos.css      # Estilos generales del sitio
├── index.html       # Página principal con el catálogo
├── producto.html    # Página de detalle de cada producto
├── productos.js     # Listado de productos del catálogo
└── README.md
```

## Correrlo localmente

```bash
git clone https://github.com/milagros-figueroa/Sandbox.github.io.git
cd Sandbox.github.io
```

Abrí `index.html` en tu navegador. No necesita instalación ni dependencias.
